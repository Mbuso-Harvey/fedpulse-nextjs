# Procurement Intelligence Documentation

Welcome to the central documentation repository for the Procurement Intelligence platform.

This directory consolidates all platform documentation into logical functional areas, moving away from the legacy chronological "wave" structure.

## Directory Structure

### 1. `product/`
Vision, roadmaps, business model, and product definitions.
- `overview/`: Core project overview and roadmaps.
- `business_model/`: Monetization, economics, and packaging.
- `intelligence_products/`: Specific features and capabilities.
- `future_expansion/`: Expansion plans.

### 2. `architecture/`
System design, manifests, and API specifications.
- `core/`: Core architecture diagrams and specifications.
- `api/`: Production API contracts.
- `manifest/`: Platform manifests.

### 3. `data_engineering/`
Schemas, AI Intelligence modules, agents, and knowledge graphs.
- `database/`: Supabase schemas and migrations.
- `sources/`: Data source definitions and scraping logic.
- `intelligence_modules/`: AI models and pipeline specs.
- `knowledge_graph/`: Semantic graph blueprints.
- `autonomous_agents/`: AI agents for pricing, compliance, etc.

### 4. `operations/`
Deployment, recovery, hardening, and governance constitutions.
- `manual/`: Operating manuals.
- `recovery/`: Disaster recovery protocols.
- `governance/`: AI and platform constitutions and rules.
- `validation/`: QA and success metrics.
- `distribution/`: Deployment packages.
- `launch_hardening/`: Security and hardening steps.
- `stabilization/`: Post-launch stabilization.

### 5. `history/`
Chronological records, legacy build logs, and past release trains.
- `build_logs/`: Chronological logs of platform builds.
- `version1_launch/`: Specific launch train logs.
- `wave15_platform/`: Archived wave logs.

---
*Note: This structure was implemented to improve maintainability and discoverability across the growing engineering team.*
