# Federal Procurement Intelligence Network Operating Manual

Created: 2026-06-16 17:08:53

## Project Mission

Build an AI-powered Federal Procurement Intelligence Network for Canada.

The objective is not to create another tender search website.

The objective is to transform public Government of Canada procurement data into business intelligence that helps companies decide which opportunities to pursue and why.

## Operating Rules

1. Document everything.
2. Use Python scripts whenever possible.
3. Assume no programming knowledge.
4. Maintain recovery and handover notes.
5. Build intelligence assets, not just dashboards.
6. Every sprint must create a business asset.
