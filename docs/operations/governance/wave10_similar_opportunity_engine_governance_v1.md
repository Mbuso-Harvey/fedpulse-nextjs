## Product Status

similar_opportunity_engine_certified

## Purpose

The Similar Opportunity Engine compares opportunities using graph-backed semantic fingerprints.

## Governance Rules

1. Opportunity similarity must be based on graph-backed fingerprints.
2. Similarity scores must be reproducible.
3. Similarity matches must include explainability.
4. V1 uses synthetic graph-slice opportunity variants; future versions will compare real tender-level opportunity profiles.
5. Supplier, buyer, pricing, technical, compliance, and evaluation overlap must remain separately visible.
