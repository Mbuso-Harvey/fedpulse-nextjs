# PLU Architecture V2 Constitution Amendment

Created: 2026-06-25 07:56:47

## Amendment: Canonical Evidence Before Intelligence

The platform shall treat canonicalized evidence as the preferred input for semantic classification and downstream intelligence.

## New Principles

### 0027 Canonicalization Before Classification

Grounded statements must be normalized and canonicalized before PLU classification whenever possible.

### 0028 Duplicate Evidence Must Not Inflate Intelligence

Repeated extracted statements must be preserved through provenance but must not inflate procurement counts, classification counts, or trend metrics.

### 0029 Provenance Is Mandatory

Every canonical statement must preserve the original source statements that produced it.

### 0030 Segmentation Before Semantic Learning

Semantic pattern learning should operate on canonical and segmented statements, not duplicated raw extraction blocks.

### 0031 Normalization Is Not Deletion

Unicode cleanup, OCR correction, and whitespace normalization may improve text quality, but original source text must remain available through provenance.
