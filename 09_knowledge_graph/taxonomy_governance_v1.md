# Taxonomy Governance V1

Created: 2026-06-22 00:03:57

## Purpose

This registry contains the canonical procurement requirement taxonomy.

## Governance Rules

Raw Text
    -> Named Entity
    -> Taxonomy Match
    -> Canonical Name
    -> Knowledge Graph

If no taxonomy match exists:

Raw Text
    -> Discovery Queue
    -> Human Review
    -> Taxonomy Expansion

## Principles

- Never discard unmatched entities
- Prefer canonical names
- Preserve aliases
- Maintain auditability
- Expand taxonomy through evidence
