# PSOP Governance V1

Created: 2026-06-27 21:23:24

## Governance Purpose

PSOP governance ensures that semantic procurement objects remain evidence-backed, versioned, explainable, and ready for knowledge graph use.

## Rules

1. No object without evidence.
2. No object without an object type.
3. No official object without lifecycle state.
4. No graph node without semantic object lineage.
5. No embedding without semantic object ID.
6. No intelligence product should consume raw text when a semantic object exists.
7. Registry promotion remains governed by PKV versioning.
8. Discovery objects remain separate from official objects until approved.

## Lifecycle Governance

Draft and candidate objects may be generated automatically.

Approved, embedded, graph_ready, and graph_published states require governance checks.

## Evidence Standard

Every object must preserve at least one of:

- supporting pattern ID
- supporting expression ID
- official registry ID
- ontology domain ID
- source provenance chain
