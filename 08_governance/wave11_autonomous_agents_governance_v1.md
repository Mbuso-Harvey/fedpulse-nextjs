## Purpose

Wave 11 creates the autonomous agent layer for the Procurement Intelligence Platform.

## Launch Discipline

Wave 11 is bounded and launch-focused. Agents must orchestrate existing certified Wave 10 products rather than create unrelated new product categories.

## Governance Rules

1. Agents must use certified Wave 10 intelligence outputs.
2. Agents must produce deterministic, auditable launch-safe artifacts.
3. Agent outputs must preserve reasoning, evidence, and task lineage.
4. Agents are decision-support workers, not uncontrolled autonomous systems.
5. Human review remains required for bid/no-bid and commercial decisions.
6. New agent concepts beyond the Wave 11 launch scope go to the post-launch roadmap.
