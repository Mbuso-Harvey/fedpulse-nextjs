# Semantic Graph Search Governance V1

Created: 2026-06-29 22:06:49

## Purpose

Semantic Graph Search is the first graph-powered intelligence product in Wave 10.

It searches KG-1.0 concepts using:

- canonical node text
- node type
- domain context
- related graph terms
- relationship evidence
- confidence scores

## Product Status

semantic_graph_search_certified

## Graph Version

KG-1.0

## Product Version

0.1.0

## Governance Rules

1. Search results must identify the graph node returned.
2. Search results must include explainability.
3. Rankings must include score components.
4. Search must use KG-1.0 exports or derivative indexes.
5. Search outputs must preserve graph version and product version.
6. Future API responses must include the same explainability layer.
